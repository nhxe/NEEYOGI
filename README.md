# 🌾 NEEYOGI – Smart Crop Prediction System

## 📘 Project Overview
**Neeyogi** is an AI-driven crop recommendation and analysis platform that helps farmers make data-informed decisions on what to grow, when to grow, and how to grow efficiently.  
It integrates **Hyperspectral Imaging (HSI)**, satellite data, soil analytics, and **machine learning models** to predict the best-suited crops for a particular region based on soil type, climatic conditions, and current market trends.

Farmers can interact in multiple languages and receive region-specific insights and market-based crop alternatives — bringing precision agriculture to every field.

---

## ⚙️ Tech Stack
- **Frontend:** React (Vite + TypeScript)  
- **UI Library:** shadcn/ui, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **AI Models:** Random Forest, SVM, CNN (for Hyperspectral Image analysis)  
- **APIs:** OpenWeatherMap, Soil Data APIs, Market Trend APIs  

---

## 🚀 Features
✅ AI-based crop prediction using soil, weather, and satellite inputs  
✅ Hyperspectral image analysis for crop health monitoring  
✅ Multilingual support (English, Kannada, Hindi)  
✅ Market trend-based recommendations and profit estimation  
✅ Personalized suggestions based on farmer inputs  
✅ PDF report generation with insights and alternative crop recommendations
